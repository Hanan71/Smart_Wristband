# Smart Wristband ⌚🧠📍
### Software Engineering System Design & Specification

An in-depth Software Requirements Specification (SRS) and system architecture study for an intelligent wearable wristband and caregiver monitoring platform designed to assist Alzheimer’s patients with real-time location tracking, geofencing, and emergency safety workflows.

---

## 💡 Overview
**Smart Wristband** is an academic Software Engineering case study focused on the **Analysis, Requirements Engineering, and System Architecture Modeling** phases. 

The project documents the end-to-end architectural blueprints, data flow diagrams, and functional specifications necessary to build a connected healthcare monitoring system for Alzheimer's patients and their caregivers.

> 🎓 **Academic Context:** Developed as part of the Software Engineering coursework at **Shaqra University** (College of Computing and Information Technology).

## 🌟 Key Functional Specifications Included
* 📍 **Patient Telemetry & Tracking:** Requirements for GPS location streaming and low-power beaconing.
* 🚨 **Emergency SOS Dispatch:** Workflows for instant one-touch distress alerts to caregivers.
* 🛡️ **Geofencing & Safe Zones:** Logic and triggers for perimeter breach notifications.
* 🩺 **Fall & Health Anomaly Detection:** Theoretical modeling for biometric and accelerometer sensor integration.

---

## 📐 System Modeling & Architectural Artifacts Covered
* **Software Requirements Specification (SRS):** Full functional and non-functional requirements (Security, Reliability, Latency).
* **UML Diagrams & Interaction Flows:** Use Case scenarios, sequence diagrams, and actor interactions.
* **Caregiver & Patient Workflows:** End-to-end system and data flow designs.
